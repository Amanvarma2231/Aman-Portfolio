## 🌟 Portfolio Overview

This is the official portfolio and engineering showcase of **Aman Varma**, designed according to 2026 modern developer portfolio standards (Dark Glassmorphism, Command Palette, Interactive Terminal CLI, and live API telemetry).

### 🚀 Key Features

- 🖥️ **Interactive Developer CLI Terminal**: Built-in bash-like terminal supporting `help`, `cat resume`, `skills`, `projects`, `curl https://npcrm-1.onrender.com/api/health`, `sudo hire-me` (with confetti animation!), and tab autocomplete.
- ⚡ **Command Palette (`Ctrl + K` / `Cmd + K`)**: Instant keyboard navigation, quick search, and deep links across the entire portfolio.
- 🛠️ **System Architecture Simulator**: Step-by-step visualizer modeling client authentication, rate limiting, Qwen 2.5 LLM inference, schema validation, and database transactions.
- 📱 **Mobile-First & Ultra Fast**: Sub-second load times, responsive breakpoints, smooth scrolling, and accessible typography.
- 📄 **Digital Resume Modal**: Clean, interactive resume reader with instant PDF export and print formatting.
- 🔒 **Production Security Standards**: Showcases zero-trust API architecture, CSRF mitigation, session auth, and OAuth 2.0.

## 💻 Local Development Setup

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/Amanvarma2231/Aman-_Portflio.git

# 2. Navigate to project directory
cd Aman-_Portflio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Production Build
```bash
npm run build
npm run preview
```

## 🚀 Deployment

### Deploy to Vercel (Recommended)
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)
```bash
npm install -g vercel
vercel
```

### Deploy to Render
1. Connect your repository on Render.
2. Select **Static Site**.
3. Build Command: `npm install && npm run build`
4. Publish Directory: `dist`
